模擬界線：
- 規模曲線僅示意，無實驗數值或特定模型預測。
- 推論實驗假設 k 次取樣獨立、每次正確率固定為 p，覆蓋率 C = 1 − (1 − p)^k。
- q 是「使用理想驗證器的機率」；其餘情況隨機選一個答案。因此最終答對率為 qC + (1−q)p。這是教學混合模型，非真實驗證器準確率模型；不代表原論文實測。
- 隨機取樣結果會波動；理論機率與單次演示結果分開呈現。
- 程式代理、工作流動畫、few-shot 和測驗範例由本教學編寫，沒有呼叫真實 LLM、執行程式碼或更新模型權重。
- 教學進度儲存在此瀏覽器 localStorage；受限瀏覽器下會退回當次記憶體。
